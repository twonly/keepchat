想把和 AI 的讨论保存下来，发给同事。怎样让上下文也被保留下来？

好对话，值得完整地留下。

把问题、回答和追问放在同一份记录里。接收方不仅能读到结论，也能看见思考是怎样一步步展开的。

从对话，到一份可以分享的记录

  1. 保留上下文：问题与约束和答案一样重要。
  2. 核对内容：检查图片、表格和代码是否完整。
  3. 选择格式：按阅读、打印或编辑的需要保存。
分享之前，先确认记录中没有不适合公开的信息。
HTML、PDF 和 Markdown 分别适合什么场景？

让格式适合接下来的用途。

文件格式适用场景阅读方式
HTML保留排版，离线分享浏览器打开
PDF打印阅读，固定分页PDF 阅读器
Markdown整理文字，继续编辑文本编辑器

示例代码也可以保留缩进：

const record = {
  title: "一段值得保留的对话",
  format: "HTML",
  offline: true
};
