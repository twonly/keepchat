留存 · KeepChat，把一段值得保存的 ChatGPT 对话，变成可以离线阅读和分享的文件。

无需 API Key，无需注册留存账号。打开目标对话，点击插件，核对预览后保存。插件读取页面已呈现的原文与样式，不调用 AI 改写内容。

【1.0.5 增强：应对 ChatGPT 长对话自动卸载】
对话很长时，ChatGPT 会随着滚动卸载屏幕外的消息，只保留附近内容。留存会自动滚动扫描当前分支，逐轮收集、合并并去重，避免只保存当前位置加载的片段。
• 修复不同轮次复用临时编号时，早先内容可能被覆盖的问题。
• 弹窗明确标注“当前页面”局部数量；扫描完成后，预览显示实际收集的消息和图片总数。
• 读取时自动切回原对话，完成后返回预览。中途切换到后台会停止并提示重试。
• 改善手机排版，保留表格可读列宽，避免桌面定位元素撑宽页面。

【三种保存方式】
• HTML：将文字、代码、表格与可读取的图片保存在单个文件中。接收方下载后用浏览器打开即可，无需安装插件或登录 ChatGPT。
• Markdown：保留文本结构，方便继续整理、编辑。
• PDF：通过浏览器打印窗口选择“另存为 PDF”，适合打印与存档。

【先预览，再分享】
• 支持普通对话、/share/ 和 /s/t_… 分享页，以及多轮对话。
• 自动滚动收集长对话，按当前分支顺序保存。
• 桌面 / 手机预览；窄屏宽表格可以在表格内左右滚动。
• 显示消息数量、图片保存情况与文件大小。
• 图片无法直接读取时，尝试裁取原页面的图片区域；仍失败时明确提示。
• 可以修改文件名、隐藏来源链接、取消读取、重试或清除本机预览。

【本机处理，透明说明】
对话和预览保存在本机，不上传给开发者，没有分析统计。读取时会访问原页引用的图片、字体和样式资源。预览缓存在本机 IndexedDB，超过 24 小时的记录在下次访问缓存时清理，也可立即手动清除。已下载文件由你自行管理。分享前请检查对话中是否含私人信息。

【使用须知】
等待 ChatGPT 回复完成后再读取。整个扫描期间请保持原对话标签页在前台，可按 Esc 取消。导出的是当前分支的页面静态快照，不是后端完整备份，也不承诺逐像素一致。扫描中仍无法加载的内容、其他分支、附件原文件、复杂图形和动态交互可能无法保留；达到扫描限制时会提示，请检查预览和保存说明。PDF 会重新分页，部分 Markdown 阅读器不支持内嵌图片。

当前界面为简体中文，可保存其他语言的对话。需要 Chrome 120 或更新版本。项目以 MIT 许可证开源，独立开发，不隶属于 OpenAI，也不是 OpenAI 官方产品。
